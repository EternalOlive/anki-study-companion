# 스터디 현황 (PC Anki)

방 중심 UI와 한국어·영어 설정을 구현했습니다. 설계 기준은 [DESIGN.md](DESIGN.md)에 정리했습니다.

현재 베타 버전은 `0.1.0`입니다. 변경 내역은 [CHANGELOG.md](CHANGELOG.md), 실제 기기 배포 확인 항목은 [RELEASE_CHECKLIST.md](RELEASE_CHECKLIST.md)를 참고하세요.

시간대 업데이트 후에는 방 참여자 모두 최신 애드온으로 업데이트하고 Anki를 재시작하세요. 예전 자정 기준 버전은 새벽 시간대 기록 업로드가 거절될 수 있습니다. 기존 일별 타이머 합계는 보존하지만 새 04:00 기준 덱 비교와 혼합하지 않으며, 오늘/주간 답변 기록은 Anki 원본에서 다시 계산합니다.

현재 구현된 기능은 다음과 같습니다.

- 오늘 공부량은 Anki 복습 기록의 답변 횟수와 저장된 답변 시간 합계로 표시
- 모바일 → AnkiWeb → PC 동기화 후 모바일에서 공부한 오늘 기록도 반영 (모바일 페이지·실시간 모바일 접속 표시는 제공하지 않음)
- 공부 상태는 PC 복습 조작으로 감지. 1분 무입력 시 잠시 멈춤, 복습 조작 시 재개. 이 상태 감지용 타이머는 오늘 공부 시간에 더하지 않음
- 같은 카드를 반복해도 답변할 때마다 카드 수 1회 기록
- 공부 시간과 카드 수의 개인 일일 목표
- 가입 없이 자동 발급되는 익명 계정과 표시용 고유번호
- 비공개 친구 그룹 생성·영문 대문자와 숫자 4자리 초대 코드 참여
- 그룹원의 오늘 동기화된 공부 시간·답변 수·목표·현재 PC 공부 상태 비교
- 친구 행을 펼쳐 오늘 답변 활동을 15분 단위 시간띠로 확인 (연속 공부 세션을 의미하지 않음)
- ‘내 기록’에서 최근 7일 답변 막대·학습 일수·공부량과 이전 7일 같은 시각까지의 기록 비교
- 같은 덱의 어제·30일 최고 기록과 내 평균 답변 속도 비교 (충분한 기록이 있을 때만)
- 친구는 고정 순서로 표시하며 이름을 누르면 목표·갱신 시각·공유가 켜진 경우 현재 덱 확인
- 친구 행의 `찌르기`로 방 친구를 콕 찌르고, 나를 찌른 친구는 툴팁으로 확인 (같은 친구 1분 1회·시간당 30회, 서버 migration 적용 후)
- 덱을 바꾸면 로컬 공부 시간과 답변 수를 덱별로 나누어 기록
- 오른쪽 스터디 패널에서 공부 중·잠시 멈춤·접속 중·마지막 기록 구분. 공부 중은 작은 초록 점, 접속 중은 기본 글자색 빈 원으로 표시
- 관리 화면에서 한국어·영어 선택 (첫 실행은 Anki 언어 기준)
- 관리창은 방·초대 코드 복사, 일일 목표, 언어 순서로 구성합니다. 목표와 언어는 저장할 때 함께 적용하며 취소하면 변경하지 않습니다.
- 방 생성·참여와 계정 연결·기존 계정 로그인은 각각 별도 화면에서 진행합니다. 계정 연결은 선택 사항입니다.
- `K7M-2RX` 형태의 자동 표시 코드: 언어와 무관하게 유지, 초대 코드·로그인 수단과 분리
- 시간·카드 기록을 `현재 / 일일 목표` 형태로 비교

Anki를 처음 열면 익명 계정과 고유번호가 자동으로 만들어집니다. 별도 가입 없이 `도구 > 스터디 현황`에서 바로 그룹을 만들거나 서버가 자동 발급한 4자리 초대 코드로 참여할 수 있습니다. 기록은 약 30초마다 동기화됩니다. 방 참여 시 공부 시간·답변 횟수·오늘 답변 시간대·현재 공부 상태가 같은 방 멤버에게 공유됩니다. 덱 이름 공유는 기본적으로 켜져 있고 관리창에서 끌 수 있으며, 카드 내용은 공유하지 않습니다.

방의 날짜는 모든 사용자에게 **방에서 정한 시간대의 새벽 4시** 기준으로 바뀝니다. 한 방은 방장을 포함해 최대 8명이며, 모든 참가 경로에서 서버가 상한을 검사합니다. 초대 코드 입력은 계정당 10분에 8회로 제한되며, 방장은 기존 멤버와 기록을 유지한 채 새 초대 코드를 발급해 이전 코드를 폐기할 수 있습니다. 이 제한은 소규모 베타에서 무차별 입력을 늦추는 장치이며, 새 익명 계정을 계속 만드는 공격까지 막는 강한 보안 경계는 아닙니다.

2026-10-04 초대 코드 보호 기능을 운영 서버에 적용했습니다. 기존 사용자는 새 애드온으로 업데이트해야 방에 새로 참여할 수 있습니다. 이미 참여한 방과 기록은 유지됩니다.

그룹을 만들거나 참여하면 PC의 Anki에 저장된 오늘 복습 기록을 가져옵니다. 방 참여 이전이나 애드온 설치 이전 기록도 포함합니다. 반복 답변은 각각 1회이며 수동 일정 변경·FSRS 재예약은 답변으로 세지 않습니다. 시간은 Anki가 저장한 답변 시간 합계이므로, 실제 앉아 있던 시간과 다르고 Anki의 답변 시간 제한 설정 영향을 받습니다. 일자 경계는 방 공통 시간대의 새벽 4시입니다. 방 생성 시 PC 시간대를 기본으로 선택하며, 생성 후에는 변경할 수 없습니다. 기존 방은 Asia/Seoul을 유지합니다. Anki 자체 설정을 변경하지 않으므로 PC의 Anki 학습일 설정이나 현지 시간대와 다르면 통계가 다를 수 있습니다. 시간대 그래프는 04시부터 다음 날 04시까지이며, 서머타임 종료로 반복되는 시각은 같은 구간에 합산합니다.

고유번호는 표시용 식별자이며 로그인 비밀번호가 아닙니다. 같은 계정의 여러 PC가 동일한 Anki 복습 기록을 보내도 컬렉션 생성 시각·복습 ID·카드 ID로 중복을 제거합니다. 카드 내용은 전송하지 않습니다. 방 화면은 마지막 서버 합계를, 방에 참여하지 않았을 때는 로컬에서 읽은 기록을 표시합니다. 미전송 복습 기록과 방별 전송 확인 상태는 로컬에 보관하고 재시작·인터넷 복구 후 다시 전송합니다. PC에서 Anki 동기화가 끝나면 즉시 갱신하며 평소 방 갱신 주기는 약 30초입니다. 서버 오류가 반복되면 자동 재시도 간격을 1분에서 최대 5분까지 늘리고, 수동 재시도와 중요 상태 변경은 이 대기를 건너뜁니다. 패널이 숨겨진 동안에도 기록 전송과 접속 상태 갱신은 유지하지만 친구 목록·시간대 조회와 숨겨진 화면 렌더링은 멈춥니다.

기존 PC 활동 시간은 보존하지만 새 복습 기록 합계에 더하지 않습니다. 개인 덱의 어제·최고 속도 비교는 계속 이 PC의 기존 활동 기록 기준이며 모바일 기록을 포함하지 않습니다. 복원·동기화 중 로컬 기록이 잠시 빠져 보여도 다른 기기의 서버 기록을 자동 삭제하지 않습니다. 이 PC에서 관찰한 실행 취소/다시 실행은 변경 버전으로 반영합니다. 모바일에서 이전에 공유한 답변을 취소하거나 오래된 백업으로 되돌리는 경우의 삭제 병합은 아직 지원하지 않습니다.

패널은 좁아지거나 글자가 커지면 시간·답변을 세로로 배치하고 친구 행을 두 줄로 나눕니다. Anki 상단 메뉴 오른쪽의 사이드바 아이콘 하나로 접고 펼칩니다. 버튼 위치는 그대로 유지되고 펼칠 때 마지막 패널 너비를 복원합니다.

내 시간·답변 수치를 누르면 해당 목표를 바로 수정하거나 해제할 수 있습니다. 방이 없으면 패널에서 바로 방 생성·코드 참여를 시작합니다. 관리창의 `초대 복사`는 방 이름·현재 코드·참여 방법을 복사하며, `기록 반영`을 펼치면 이 PC 기록 확인·저장·방 공유·친구 조회의 마지막 성공 시각을 볼 수 있습니다. 정상 상태에서는 추가 안내를 표시하지 않고, 오류나 오래된 전송 대기만 패널에 표시합니다.

2026-10-03 서버 전환 이후에는 모든 참가자가 새 애드온으로 업데이트해야 합니다. 계정과 방은 유지하며, 구형 서버 기록은 보관하되 새 화면에는 새 방식으로 전송한 기록만 표시합니다.

로그인은 이메일 발송이 필요 없는 **아이디·비밀번호 방식**입니다. `관리 → 계정 → 통합 계정 만들기`에서 비회원 기록과 방을 유지한 채 연결합니다. 다른 PC에서는 `다른 PC의 계정으로 로그인`을 사용하세요. 아이디는 영문 소문자·숫자·밑줄 4~24자, 비밀번호는 10자 이상입니다. 계정 생성 때 표시되는 **복구 코드는 별도로 안전하게 보관**하세요. 비밀번호와 복구 코드를 모두 잃으면 자동 복구할 수 없습니다. 현재 비밀번호를 알고 있다면 관리창에서 복구 코드를 재발급할 수 있습니다.

로그인 서버는 2026-10-03 운영 프로젝트에 배포했으며, 독립 테스트 계정으로 연결 전후 UUID·방 유지, 별도 클라이언트 로그인, 두 기기 기록 합산·재전송, 비밀번호/복구 코드 변경과 재사용 거부, 세션 갱신을 검증했습니다. 자동 테스트에서는 복원·재설치·두 기기 중복 경계도 검증했지만, 실제 물리 PC 두 대에서의 최종 사용 확인은 별도입니다. 개발·운영 설명은 [LOGIN_SETUP.md](LOGIN_SETUP.md)를 참고하세요. 기존 이메일 계정은 호환 로그인 옵션으로 남아 있고, 이메일 발송은 이번 범위에서 제외했습니다.

휴대폰 웹 조회는 이후 단계입니다. 카드 지표의 새 카드·복습 카드 구분 같은 세부 조정은 [TODO.md](TODO.md)에 남겨두었습니다.

### 시간대와 주간 기록

친구 행을 누르면 방 시간대의 04시부터 다음 날 04시까지 답변 활동이 나타납니다. 표시된 구간은 답변이 저장된 15분 구간이며, 사이의 빈 시간을 공부 시간으로 채우지 않습니다. 서버에 원본 복습 기록이 없는 구버전 참가자는 시간대 기록을 확인할 수 없다고 표시합니다. 같은 방 멤버만 집계된 시간대를 조회할 수 있고 개별 답변 ID나 카드 ID는 내려주지 않습니다.

웹 클라이언트와 서버 RPC의 현재 계약은 [PUBLIC_API_CONTRACT.md](PUBLIC_API_CONTRACT.md), 아이디 인증 HTTP 계약은 [ACCOUNT_AUTH_API.md](ACCOUNT_AUTH_API.md)를 참고하세요.

‘내 기록’의 주간 막대는 이 PC에 동기화된 전체 덱의 답변 횟수입니다. 최근 7일과 이전 7일을 비교하며, 두 기간의 마지막 날은 같은 시각까지 집계합니다. 오늘은 진행 중입니다. 과거 14일 조회는 로컬 집계용이며 이 기능 때문에 과거 원본 기록을 추가 업로드하지 않습니다. 과거 목표가 보존되지 않아 목표 달성 일수는 표시하지 않습니다. 아래의 덱별 속도 비교는 기존 PC 활동 시간 기준을 유지합니다.
