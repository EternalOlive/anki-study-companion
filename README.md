# 스터디 현황 (PC Anki)

방 중심 UI와 한국어·영어 설정을 구현했습니다. 설계 기준은 [DESIGN.md](DESIGN.md)에 정리했습니다.

현재 구현된 기능은 다음과 같습니다.

- PC Anki 복습 중 공부 시간 자동 측정
- 1분 동안 입력이 없으면 자동 일시정지, 다음 카드 답변 시 자동 재개
- 같은 카드를 반복해도 답변할 때마다 카드 수 1회 기록
- 공부 시간과 카드 수의 개인 일일 목표
- 가입 없이 자동 발급되는 익명 계정과 표시용 고유번호
- 비공개 친구 그룹 생성·영문 대문자와 숫자 4자리 초대 코드 참여
- 그룹원의 오늘 시간·카드 수·목표·현재 공부 상태 비교
- 같은 덱의 어제·30일 최고 기록과 내 평균 답변 속도 비교 (충분한 기록이 있을 때만)
- 친구는 고정 순서로 표시하며 이름을 누르면 목표와 갱신 시각 확인
- 덱을 바꾸면 로컬 공부 시간과 답변 수를 덱별로 나누어 기록
- 오른쪽 스터디 패널에서 공부 중·잠시 멈춤·접속 중·마지막 기록 구분. 공부 중은 작은 초록 점, 접속 중은 기본 글자색 빈 원으로 표시
- 관리 화면에서 한국어·영어 선택 (첫 실행은 Anki 언어 기준)
- 관리창은 방·초대 코드 복사, 일일 목표, 언어 순서로 구성합니다. 목표와 언어는 저장할 때 함께 적용하며 취소하면 변경하지 않습니다.
- 방 생성·참여와 이메일 연결·기존 계정 로그인은 각각 별도 화면에서 진행합니다. 계정 연결은 선택 사항입니다.
- `K7M-2RX` 형태의 자동 표시 코드: 언어와 무관하게 유지, 초대 코드·로그인 수단과 분리
- 시간·카드 기록을 `현재 / 일일 목표` 형태로 비교

Anki를 처음 열면 익명 계정과 고유번호가 자동으로 만들어집니다. 별도 가입 없이 `도구 > 스터디 현황`에서 바로 그룹을 만들거나 서버가 자동 발급한 4자리 초대 코드로 참여할 수 있습니다. 기록은 약 30초마다 동기화됩니다.

그룹을 만들거나 참여하면 그 시점 이전에 로컬 확장 프로그램이 기록해 둔 오늘의 공부 시간과 카드 수도 즉시 그룹 기록에 반영됩니다. 이후에는 오늘 누적값을 갱신하므로 같은 기록이 중복으로 더해지지 않습니다.

고유번호는 표시용 식별자이며 로그인 비밀번호가 아닙니다. 다른 PC에서도 같은 기록을 쓰고 싶을 때만 이메일을 연결하고, 확인 메일의 링크를 누른 뒤 비밀번호를 설정하면 됩니다.
